# Współtworzenie

## Zgłaszanie błędów
Otwórz zgłoszenie i opisz: co zrobiłeś, czego oczekiwałeś, co się stało. Dołącz nazwę narzędzia (Claude Code czy Gemini CLI) i system, na którym pracujesz.

## Propozycje zmian
1. Rozgałęź repozytorium i utwórz gałąź od `main`.
2. Zmiany w treści skilla wprowadzaj w obu plikach naraz — `SKILL.md` (Claude Code) i `brief-lite.toml` (Gemini CLI). Rozjazd między nimi to najczęstszy błąd w tym repozytorium.
3. Sprawdź zmianę na żywo: zainstaluj plik u siebie wg instrukcji z README i przejdź cały przebieg od `/brief-lite` do gotowego posta.
4. Opisz w prośbie o zmianę, co i po co zmieniasz.
